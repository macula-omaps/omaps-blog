This post distills the API governance methodology developed for the Xomaps® (信朴科技) location management system: a risk catalog of 17 control measures for enterprise internal systems, designed for architecture reviews, security requirement writing, and threat modeling.

Scope: enterprise internal systems — systems where the data is a company-level asset and every user is both a user and a maintainer of that asset. This includes command channels (consolidated command layer on the write side) / multi-tenant middle platforms / open APIs (MCP, mini-program mobile clients). Purpose: a standard risk catalog for architecture reviews, security requirements, and threat modeling. Positioning: belongs to the “API Access and Integrity Risk” category, alongside Transport Security and Authentication Security.
